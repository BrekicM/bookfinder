# Agora: via WooCommerce Store API, author and format parsed from the product title

Agora (agoraknjige.rs) is a WooCommerce shop like Booka, and its Store API (`/wp-json/wc/store/v1/products?search=`) is confirmed working — same shape as ADR 0009, so `AgoraClient` implements `find_editions()`/`search_titles()` directly against it rather than the sitemap-and-shortlist pattern used by Laguna/Vulkan/Čarobna knjiga/Geopoetika. Unlike Booka, there's no `pisac` taxonomy or any other structured author field, in the API or on the product page — but every sampled product title (10/10) follows a strict `"Author: Title"` colon-delimited convention (e.g. `"Vladimir Pištalo: LUKE"`), so `AgoraClient` splits on the first colon instead of making a second request. A title with no colon is treated as an unresolved-author edition (author `""`, falls back to title-only matching in `matches_book()`), not skipped — the pattern hasn't been verified across the full ~493-product catalog, so this is a graceful degradation, not a confirmed-unreachable branch.

Titles are scraped verbatim, including their all-caps casing — consistent with the existing precedent (CONTEXT.md's Language definition) that Edition data stays exactly as the store returns it, rather than risk mangling Serbian-specific capitalization with a naive normalization.

Agora also genuinely lists multiple distinct editions of the same book under the same title+author (e.g. a 2008 Latin-script printing and a 2023 Cyrillic-script printing of Pištalo's *Tesla*, different SKUs/prices/stock) — this is real catalog data, not a bug, and confirms Script is worth parsing here too: Agora's product pages carry a structured `"Pismo: latinica/ćirilica"` line, the same shape Booka already exposes, so `AgoraClient` populates `Edition.script` from it (see the CONTEXT.md Script update below).

One listing bundles the book with an audio CD, titled with a `"... + ZVUČNA KNJIGA NA CD-U"` suffix. Used raw, that suffix would become part of `Book.title` and give the bundle a different `identity_key()` than the plain print edition of the same book — silently fragmenting one Book into two in the wishlist/matching model. `AgoraClient` detects this (and similar bundle-marker) suffixes, strips them into `Edition.format_label`, and uses the cleaned title for `Book.title` — so the bundle correctly shares identity with the plain print edition. Only one such listing exists today; the detection is a small, targeted suffix check, not a general parser.
