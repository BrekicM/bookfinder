# Availability collapses to a single "not available" state

Some stores expose a real distinction between "never carried" and "temporarily out of stock" — confirmed on Laguna, which shows explicit "Rasprodato" text and even a middle state ("not in physical stores but orderable online"). The app deliberately does not surface this distinction: every non-purchasable result reads as "not available," to keep the MVP's Availability model simple and consistent across stores with uneven data richness. Revisit once individual store integrations mature.
