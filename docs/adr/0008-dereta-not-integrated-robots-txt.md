# Dereta is not integrated — its robots.txt disallows AI crawlers

A fourth Serbian bookstore, Dereta (dereta.rs), was proposed as an addition alongside Laguna, Vulkan, and Delfi, with the same investigate-the-live-site methodology that found Delfi's real search API (ADR 0004). Before any product-page or search-endpoint probing began, `dereta.rs/robots.txt` was checked and found to explicitly disallow `ClaudeBot` and `anthropic-ai` by name (alongside GPTBot, CCBot, Bytespider, Amazonbot, and other AI crawlers). Investigation stopped there — the decision was to respect the disallow rule rather than continue fetching under a different user-agent or otherwise route around it.

Dereta therefore has no BookstoreClient, is not in the `Bookstore` enum, and was never technically evaluated (no confirmation either way on sitemap availability, product-page rendering, search API, or Top-lista data). This is not a "we tried and it doesn't work" case like ADR 0003's original Delfi assessment — it's "we didn't try, because the site asked us not to." Revisit only if Dereta's robots.txt policy changes, or explicit permission is obtained from Dereta to integrate programmatically.
